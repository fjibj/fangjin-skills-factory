# 成片验收关卡（每段必过，再交用户）

> 观感 = 每个成片是否经得起逐秒细看。以下每项都要真过，不是口头承诺。

## 画面与内容
- [ ] 页面所有占位已替换为真实数据（视觉核验：无 SVG 残留、无假数据板）
- [ ] 需求要求的**每个展示方面**都在成片里有真实画面（不只口播）
- [ ] 演示内容与提示词/口播一致（说"黄帽"画面就是真黄帽；标的是目标对象就是该对象）
- [ ] 标注/识别框**真实贴合目标**，无悬空、错位、漏标、虚标
- [ ] 无乱码、无黑屏、无过渡动画未完成态
- [ ] 界面无调试标签（如"简化版/非录屏功能"）——正式截图/成片要藏掉

## 音画
- [ ] 字幕与配音逐句同步（抽帧核验关键句）
- [ ] 成片有 Video + Audio 双流（`ffprobe`/`ffmpeg -i` 核验）
- [ ] 时长 = 配音时长（`-shortest` 后），且 < 交付时长上限
- [ ] 封面/过渡页不叠加鼠标；页内点击位置精准落在按钮上

## 数据完整性
- [ ] 成片命名规范、参数(编码/采样率/声道口径)统一
- [ ] 合并后的总片时长校验通过（< 交付上限）
- [ ] 关键帧(无字幕)已备好，供文档/素材引用
- [ ] 原始帧、配音、成片均留存，可随时重录/重合成

## 交付前确认（关键动作）
- [ ] 涉及内容真实性的节段先出**预览图**确认，通过再改视频
- [ ] 交付时给出文件路径，用户能直接打开
